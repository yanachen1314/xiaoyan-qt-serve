# 微信公众号菜单关键字回复计划

## 目标

完善微信公众号文本消息回复能力：关注后展示功能菜单，用户回复菜单编号或关键字后，从系统配置表读取对应菜单内容并返回。

## 配置设计

- `wechat.subscribe.reply`：关注后默认菜单内容，也作为菜单 `0` 的默认回复内容。
- `wechat.menu.reply.rules`：菜单匹配规则 JSON，配置每个菜单项的回复配置 key、关键字和是否生成验证码。
- `wechat.menu.reply.1`：获取验证码菜单内容，支持 `{code}` 占位符。
- `wechat.menu.reply.2`：小烟改写工具菜单内容。
- `wechat.menu.reply.3`：人工降重 / 降AI / 格式修改菜单内容。
- `wechat.menu.reply.4`：联系我菜单内容。

## 匹配规则

1. 文本消息内容先 `trim()`。
2. 遍历 `wechat.menu.reply.rules` 中每个菜单项。
3. 只要与菜单项 `keywords` 中任意一个关键字精确匹配，就返回该菜单项内容。
4. 菜单项设置 `generateCode=true` 时，生成验证码、保存验证码，并把回复内容里的 `{code}` 替换成验证码。
5. 没有命中菜单规则时，返回 `null`，保持原先“不回复”的行为。
6. 菜单规则读取失败时，使用代码内置默认规则兜底。
7. 菜单内容读取失败或为空时，使用代码内置默认文案兜底。
